# MyTemplate 🚀

**MyTemplate** — это легковесный шаблон для быстрого старта веб-проектов с использованием Webpack и Babel. Проект предназначен для разработки JavaScript-приложений с современной сборкой и транспиляцией кода.

## 🛠️ Технологический стек

- **JavaScript** (ES6+) — основной язык разработки
- **Webpack** — сборщик модулей
- **Babel** — транспилятор JavaScript
- **Node.js** — среда выполнения

## 📦 Установка и запуск

### Предварительные требования
- Установленный [Node.js](https://nodejs.org/) (версия 12 или выше)
- Установленный npm (входит в состав Node.js)

### Инструкция

1. **Клонируйте репозиторий**
   ```bash
   git clone https://github.com/your-username/MyTemplate.git
   cd MyTemplate
   ```

2. **Установите зависимости**
   ```bash
   npm install
   ```

3. **Запустите проект в режиме разработки**
   ```bash
   npm run dev
   ```
   Проект будет доступен по адресу `http://localhost:8080`.

4. **Соберите проект для продакшена**
   ```bash
   npm run build
   ```
   Собранные файлы будут находиться в папке `dist`.

## 💻 Примеры использования

### Базовый пример
Создайте файл `src/index.js` с простым кодом:

```javascript
const greet = (name) => {
  console.log(`Hello, ${name}!`);
};

greet('World');
```

### Запуск в режиме разработки
После запуска `npm run dev`, откройте браузер и проверьте консоль разработчика — вы увидите сообщение "Hello, World!".
